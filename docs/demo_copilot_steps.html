How to run the prototypes locally

Start the MLOps dashboard

# from repo root where 'dashboard/' and 'ml_algorithms/' exist
python -m venv .venv
source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements_ml.txt
uvicorn dashboard.app:app --reload --port 9000
# then open: http://localhost:9000/dashboard

Start the ML Conversation Chatbot

# from repo that contains ml_chatbot/
python -m venv .venv
source .venv/bin/activate
pip install -r ml_chatbot/requirements.txt
export DASHBOARD_URL=http://localhost:9000
export REPO_PATH=/path/to/local/repo   # used by code search
uvicorn ml_chatbot.server:app --reload --port 8001
# Health check: curl http://localhost:8001/health
# Chat example:
curl -X POST http://localhost:8001/chat -H "Content-Type: application/json" -d '{"query":"Show me prototype performance"}'

Security & Governance highlights (must-do before exposing)

  • Whitelist allowable algorithm module names — DO NOT accept arbitrary module names from users.
  • Run user-triggered training in isolated workers/containers with CPU/memory/time limits.
  • Enable authentication & RBAC on dashboard and chatbot endpoints.
  • Log and audit run requests, redacting PII, and store experiment metadata (dataset, seed, hyperparams).
  • Consider asynchronous job queue (Celery/RQ/K8s Jobs) and a persistent results store (SQLite/MLflow/Postgres).
